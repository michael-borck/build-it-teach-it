# Build It, Teach It

*Hands-on AI Projects for the Classroom* by Michael Borck.

A project and teaching companion to [HandsOnAI](https://github.com/michael-borck/hands-on-ai): chat, RAG, agents, workflows, loops, evaluation, vision, voice, classroom projects and assessment.

## Structure

- `index.qmd`: preface and reading guide
- `chapters/`: twelve chapters in four parts
- `appendices/`: module map, project template and classroom checklist
- `book-design.css` / `book-design-epub.css`: house design assets
- `_quarto.yml`: HTML, PDF and EPUB configuration

## Build

```bash
quarto render
```

For the Lorekeeper pack, the engine reads the four parts and appends interactive lessons from `lorekeeper/books/build-it-teach-it/`.
